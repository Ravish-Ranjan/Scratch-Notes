### IPV4 address

1. 32 bit address we can represent $ 2^32 $ addresses
2. can se written as  binary, hax, decimal
3. 32 bits can be divided in prefix and suffix
  1. prefix : network
  2. suffix : connection to the node
4. Classfull addressing
  1. A (0 - 127)
    1. starting with 0
    2. prefix : 8
    3. suffix : 24 bits
  2. B (128 - 191)
    1. starting 10
    2. prefix : 16
    3. suffix : 16
  3. C (192 - 223)
    1. starting 110
    2. prefix : 24
    3. suffix 8
  4. D (224 - 239)
    1. starting : 1110
    2. prefix : 32
  5. E (240 - 255)
    1. starting :  1111
5. Classless
