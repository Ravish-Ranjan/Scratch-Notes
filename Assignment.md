Assignment

Build a Task Tracker Web Application using the MERN Stack to demonstrate your understanding of full-stack development, REST APIs, database management, and React fundamentals.

Tech Stack

- Frontend: React.js
- Backend: Node.js + Express.js
- Database: MongoDB

Mandatory Features

- Create, View, Update & Delete Tasks
- (CRUD)
- Form validation
- REST APIS
- MongoDB integration
- Responsive UI
- Dynamic updates without page refresh

Deploy both frontend and backend on a

public URL

You are encouraged to implement bonus features such as filtering, sorting, notifications, reusable components and environment variables
