# Basics

cyber security : practice of protecting devices, computers, servers etc from malicious attacks

1. Cyber secuirty
  1. CIA traids : confidenciality, integrety, availability
  2. Vulnerability : flaw in system that could be exploited
  3. Threat : potential for a threat agent to exploit vulnerability
  4. Risk : potential for loss when threat happens = threat * vulnerability
  5. cyberspace : space where communication is done
  6. cyber crime : cyber-stalking, hacking, email-spoofing, not-network, phishing, malware, fraud, spam, defeamation, cyber terrorism

2. Cryptography : to provide confidenciality, integrety, authentication, control availability, non-repudation (sender can't deny)
  1. Cryptology : study of communication over non-secure channel
  2. Cryptography : process of designing system to do cryptology
  3. Cryptanalysis : breaking cryptography system
3. Goal of attacker
  1. read message
  2. find encryption key to ready all messages
  3. alter message
  4. mascurade as sender to communicate with reciever
  5. Infromation attacker can get
    1. ciphertext : only the encrypted text
    2. known plaintext : it can have both plain and cipher text
    3. chosen plaintext : attacker has temporary access of encryption machine
    4. chosen cipher : attacker has temporary access to decryption machine
4. Types of malware : virus, worm, ransomware, spyware, trojan horse,
5. Cyberkill-chain
6. Steganography : art + science of communicating in a way so that it hides existence of communication
  1. it is processes of hiding the message amoung irrelevent data to confuse cryptanalyst
7. Signal transmission threats
  1. interuption : stopped in middle of transmission
  2. interception : reading data which is being transmitted
  3. modification : sent data is modified and forwarded to reciever
  4. fabrication : attacker behaves as sender to send own data
8. Cryptography attacks
  1. passive : only confidentiality is lost , attacker only observes
    1. chosen-plaintext : choses plaintext, gets ciphertext and tries to find key
    2. chosen-ciphertext : choses ciphertext, usese target system to decrypt that and tries to find key
    3. known-plaintext : have sample of both encrypte and plaintext data and tries to find key
    4. ciphertext-only : only ciphertext is known to attacker
  2. active : tries signal transission threats to attack
    1. brute-force : trying all combination in keyspace
    2. Quantum computing attack
    3. Algorithmic attacks
    4. Hardware attack
    5. Side channel attack
    6. Dictionary attack
    7. Protocol based attack
    8. Timing/Power consumption
    9. Mathematical attacks etc
    10. buffer overflow
